# 📊 PhonePe Payment Insights Dashboard

> An interactive **Power BI dashboard** designed to analyze PhonePe transaction activity, payment value, user behavior, service usage, and transaction trends through an intuitive business intelligence interface.

---

## 🚀 Project Overview

The **PhonePe Payment Insights Dashboard** transforms transaction-level data into meaningful business insights using **Microsoft Power BI**.

The dashboard provides an interactive view of:

- 💳 Transaction performance
- 💰 Total transaction value
- 👥 Unique users
- 📈 Transaction trends over time
- 🎯 Successful transaction rate
- 👨‍👩‍👧 Age-segment contribution
- 🏦 Service-wise transaction value
- 🏆 Top users by transaction value
- 📅 Weekday vs Weekend usage
- 🔎 Interactive filtering and analysis

The project demonstrates how raw transactional data can be converted into a professional and decision-oriented BI solution.

---

## 🎯 Project Objectives

The main objectives of this project are to:

1. Analyze overall transaction performance.
2. Track transaction value and transaction volume over time.
3. Understand user contribution and behavior.
4. Compare different age segments.
5. Identify services contributing to transaction value.
6. Analyze weekday and weekend transaction patterns.
7. Highlight important KPIs using interactive visuals.
8. Build a clean and professional business dashboard.

## 📊 Dashboard Highlights

### 💳 Key Performance Indicators

The dashboard presents important KPIs such as:

- **Total Transactions**
- **Total Transaction Value**
- **Unique Users**
- **Successful Transaction Rate**
- **Month-over-Month Growth**

These KPIs provide a quick overview of overall payment performance.

---

### 📈 Transactions Over Time

A monthly trend visualization helps analyze changes in transaction value throughout the year.

This makes it easier to identify:

- Monthly fluctuations
- Growth patterns
- High and low transaction periods
- Overall transaction movement

---

### 👥 Age Segment Analysis

The dashboard includes an age-based contribution analysis to understand how different customer segments contribute to overall transactions.

Segments include:

- Millennials
- Gen X
- Gen Z
- Boomers

---

### 🏦 Service Transaction Analysis

The **Service Transaction Value Analysis** visual compares transaction value across different services.

This helps identify which services contribute significantly to the overall transaction value.

---

### 🏆 Top Users Analysis

The dashboard highlights the **Top Users by Transaction Value**, allowing users to understand the contribution of high-value customers.

---

### 📅 Weekday vs Weekend Analysis

A dedicated visualization compares transaction activity between:

- 🟣 Weekdays
- 🟪 Weekends

This provides insight into customer usage patterns throughout the week.

## 🧠 Data Analysis & Modeling

The project uses Power BI's data modeling capabilities to organize transaction and user information.

The model includes components such as:

- `All_Transactions`
- `All_Users`
- `Date_Table`
- Measures

A dedicated **Date Table** is used for time-based analysis and monthly reporting.

DAX measures are used to calculate important business metrics and KPIs.
